Multi-threading is defined as a process of running a program in a small part of mulitple functioning independently.
Multi-threading works on single-layer execution of program.
Multi-threading is supported in Java with thread classes and thread interfaces.
________________________________________________________________________________________________________________________________________________
Thread Lifecycle

New --> Runnable --> Running --> Waititng/Blocked --> Terminated

New         | Thread Object created, not started        | Thread t = new Thread(...)
Runnable    | Ready, waiting for CPU                    | t.start
Running     | CPU is executing run()                    | Threadscheduler picks it.
Waiting     | Paused for some time or event             | sleep(), wait(), waiting for I/O or lock
Terminated  | Work Finished (dead)                      | run() ends
